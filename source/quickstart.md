# Quickstart Guide ✨

Here's how to cast your very first spell using WizardAPI.

```python
from wizardapi import SpellCaster

caster = SpellCaster(api_key="your-secret-scroll")
result = caster.cast("fireball", target="goblin")

print(result)
````

**Output:**

```text
🔥 You cast Fireball on Goblin!
Goblin takes 42 fire damage.
```

**Common beginner spells:**

* `fireball`
* `heal`
* `summon_familiar`
* `invisibility`
