# Installation 🔮

To start casting spells, you must first install the WizardAPI.

## Using pip

```bash
pip install wizardapi
````

## Alternatively, clone the repository from GitHub:

```bash
git clone https://github.com/example/wizardapi.git
cd wizardapi
python setup.py install
```

## Requirements

* Python 3.8+
* Mana ≥ 50 MP
* A stable internet connection to the Arcane Realm
