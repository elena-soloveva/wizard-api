# Contributing 🛠️

We welcome all magical beings to contribute to WizardAPI.

**How to help:**

- Report bugs (preferably not the giant magical kind)
- Add new spells to the spellbook
- Improve documentation (send scrolls via pull requests)

Before contributing, please read our Code of Conduct:
[https://github.com/example/wizardapi/CODE_OF_CONDUCT.md](https://github.com/example/wizardapi/CODE_OF_CONDUCT.md)
